# Business Problem

A learner wants short Python practice that targets a concept and difficulty without hunting for exercises or receiving unsolicited answers. Ancora generates complete challenges and keeps executing, checking and requesting help distinct.

The initial learner works locally with collections, comprehensions, filtering/transformation, strings and functions. Success is a reliable loop: choose → generate → write → run → check → optional coaching → continue, with drafts and attempts preserved in later slices.

Current evidence is the fixed synthetic runner spike. Live generation, persistence/history and coaching are later work. Authentication, source ingestion, flashcards and RAG belong to the retired product direction. See programming-practice.md and ADR 0011.
