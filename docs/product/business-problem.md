# Business Problem

A learner wants short Python practice that targets a concept and difficulty without hunting for exercises or receiving unsolicited answers. Ancora generates complete challenges and keeps executing, checking and requesting help distinct.

The initial learner works locally with collections, comprehensions, filtering/transformation, strings and functions. Success is a reliable loop: choose → generate → write → run → check → optional help → continue, with saved drafts, exact attempts and reload/resume.

The implemented loop includes generated challenges, persistent practice/history, solution reveal, progressive hints and selected-attempt coaching with explicit code sharing. Automated checks use synthetic providers; live generation/hint samples were reviewed separately, while live coaching quality evaluation remains deferred. Authentication, source ingestion, flashcards and RAG belong to the retired product direction. See [the product specification](programming-practice.md) and [v1 verification](../testing/v1-completion.md).
