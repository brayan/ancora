# Schemas Package

`src/practice.ts` owns versioned runtime schemas for the practice API, including server-derived reveal metadata on sessions and assistance snapshots on attempts. Zod validates both requests and browser responses; TypeScript contracts are inferred from these schemas and re-exported by `@ancora/shared-types`.

`hints.ts` and `hints-v1.schema.json` own the public-only hint dispatch/lifecycle contracts; Python API/provider parity is checked offline.

`practice-v1.schema.json` is generated. Run `pnpm contracts:generate` after changing the canonical schemas; `pnpm contracts:check` rejects drift. Do not edit the generated file by hand. Runner reports also pass the bounded runner-protocol validator; JSON Schema alone does not validate execution evidence.

`pnpm --filter @ancora/schemas typecheck` checks this package. Python consumers remain future work; no Python service owns a separate product schema or database migration.

`coaching.ts` owns explicit-sharing requests, bounded public/source/evidence input, feedback, provenance and durable views. `coaching-v1.schema.json` is generated by the existing contract command; API and independent provider Pydantic models have parity tests. Attempts add server-owned `coachingAvailable` snapshots.
