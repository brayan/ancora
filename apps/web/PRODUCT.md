# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

A single learner practising Python locally with short coding challenges. The owner selected Next.js App Router, React, TypeScript, FastAPI and Pydantic AI, and retired authentication/source/flashcard features.

## Workflow and constraints

Concept/difficulty → generated challenge → write one pure function → run examples → check → optional requested coaching. The current slice is a fixed synthetic exercise with durable drafts, submitted attempts and reload/resume. There are no generation or paid calls. Code execution is isolated from application capabilities. See ../../docs/product/programming-practice.md and ADR 0011 for canonical product truth.

## Evidence

Synthetic positive-even exercise and real-Chrome runner checks only. No claims of model quality or production security attestation. No private code in screenshots/logs.
