# Ancora Workspace Design

The runner spike is an operation-focused learning workspace. Preserve the incumbent system sans typography, green/teal action color, restrained borders, modest radii and quiet product layout. No marketing composition or visual assets are needed to explain this code-execution tool.

Use a readable challenge column beside a larger code field on desktop, stacked on mobile. Keep run/check/Stop adjacent, results directly below, and behavior separate from technique. Use monospace for actual code/data only. Controls and status text must name their action and recovery. Explicit labels, visible keyboard focus, reduced-motion support and no horizontal page overflow are required.

This is the spike's interface, not a commitment to a final editor or product redesign. Canonical frontend structure/naming remain in docs/frontend.
